## 검증 범위

- Python: 기존 앱 72개 + 신규 통합 16개 + 이전 코어 회귀 24개 = 112개.
- 프런트엔드: 기존 카메라 계산/상태 전이 41개 + 데이터 가용성/만료/연구 BP 표시 10개 + 선택 기능 UI 4개 = 55개.
- TypeScript 검사와 Vite 프로덕션 빌드 통과. 기존과 같은 큰 JS chunk 경고가 남는다.
- BIDMC 01/02의 이전 후 검증 보고서는 원본과 모든 항목이 일치한다. 각각 맥박수 MAE 0.9367 / 0.6183 bpm, 유효 출력 471/480이다. 이 결과는 모니터 HR 수치 비교이며 PRV·혈압·의료 성능 검증이 아니다.
- 실제 BP artifact와 sample 입력의 원본/이전 NumPy CPUModel 예측이 완전히 일치한다. PyTorch를 import하지 않고 실행했다.
- 브라우저에서 BIDMC 02 재생, 맥박수/PRV 표시, source 보존, 일일 앉기·서기 검사, 커프 118/76 테스트 입력, 설문, 서버 저장, 대시보드 재조회, 새로고침 후 모드·세션 복원을 확인했다.
- 재생 EOF 후 현재 숫자가 비워지는 것과 실제 모드에서 persona 수치·가상 건강 점수가 표시되지 않는 것을 확인했다.
- 수동 응급 화면 진입·단계 진행과 미활성 red flag 상태를 브라우저에서 확인했다. 종료 확인창에서 브라우저 제어 도구가 응답하지 않아 최종 종료 저장은 API 통합 테스트로 검증했다.
- 추가 통합 테스트: 두 대상자 격리, 중복/역순/겹침 입력 거부, 구독 queue 제한, source stale와 재가동 warmup, 위조 identity/채널 불일치/외부 WS origin 거부, 경로 제한, EOF, posture 경계, 저품질 검사, 커프 분리, 체크 idempotency, 실패한 BP gate, ECG 없음·gap 후 BP 초기화, 수동 반응/응급 기록의 세션 귀속.

## 남은 범위

- 현재 혈압 모델은 정확도 채택 기준을 통과하지 못했다. 새 데이터/프로토콜로 별도 실험을 하기 전까지 앱의 모델 추정값은 unavailable이다. 실패한 모델을 우회 활성화하지 않았다.
- ESP32·ECG 기기의 실제 동기화·패킷 전송과 USB reader는 구현 범위 밖이다. 현재는 등록한 공개/녹화 파형과 명시적 synthetic 입력으로 재현할 수 있다.
- 실측 임상 임계값·리듬 판정·SpO₂ 보정·자체 호흡수 추정·실측 자동 CPR은 추가하지 않았다. 기존 카메라 탐지는 데모 모드에서만 제공한다.
- 실측 데이터가 없는 신체 영역은 Not assessed이다. 기존 가상 미션/식사/운동 기록 UI는 데모 모드에 유지하고 실측 대상자에게 자동 이식하지 않았다. 실제 검사에서는 커프·온도·혈당·설문·반응 결과를 보존한다.
- UI 변경 전후를 자동 비교하는 브라우저 회귀 스위트는 아직 없다. 기존 컴포넌트 재사용, 실제 브라우저 확인, 저장 결과 화면을 검증 근거로 사용했다.
- Python에는 기존 Starlette/httpx 사용 중단 예정 경고 1건이 남는다.

패키지와 앱 실행에는 인터넷이 필요 없다. 의존성 최초 설치 및 선택적인 연구 자료 다운로드는 별도다. 데이터·가중치는 자동 게시하거나 저장소에 복사하지 않았다.

## 혈압 모델 선택 기능 분리

- PPG 패키지에서 BP 코드를 분리해 `packages/crewsense-bp`를 별도 배포 단위로 만들었다. `backend/requirements-bp.txt`로 선택 설치한다.
- 기본 실행에서는 BP 모델·버퍼를 초기화하지 않으며 별도 패키지가 없어도 앱이 동작한다.
- 서버의 `--enable-research-bp`/`COPILOT_ENABLE_RESEARCH_BP=1`과 연구 세션의 `enable_research_bp=true`를 모두 선택해야 한다. 기존 artifact·보고서·정확도 gate는 그대로 유지한다.
- 일반 대시보드·일일 검사에서 모델 추정 카드는 숨긴다. 연구 모드의 Optional research features에서 별도로 선택한다. 커프 입력은 선택 기능과 무관하게 유지한다.
- 기본 PPG에 BP 초기화가 없다는 테스트, 선택 모드·서버 옵션 검증, 정확도 gate 우회 방지, BP 패키지 import 차단 상태의 앱 시작, UI 기본 숨김·커프 유지 테스트를 추가했다.
